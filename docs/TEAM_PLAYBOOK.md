# Playbook — 48 de ore / vibe coding

## Reguli simple
- Un singur repository principal pentru cod; fiecare lucrează pe branch separat când echipa se extinde.
- Un singur responsabil de integrare / merge; review rapid înainte de merge.
- Taskuri mici, verificabile în browser. Cere AI-ului fișierele schimbate și pașii de test.
- După fiecare schimbare: pornește aplicația, testează un scenariu bun, unul problematic, unul cu input gol.
- Prioritizează demo-ul și stabilitatea în fața complexității tehnice.

## Roluri când sosesc colegii
- Product/demo: brief, cerințe, scenarii, pitch.
- UI/UX: flux, claritate, responsive, accesibilitate.
- AI workflow: prompturi, apeluri server-side, validarea outputurilor.
- QA/integration: teste, GitHub, deploy, integrare.

Dacă sunteți doar 2–3 oameni, combinați rolurile; nu așteptați echipa ca să aveți un demo.

## Etape (nu ore rigide)
1. Confirmă regulile și criteriile de jurizare.
2. Demo determinist cap-coadă.
3. Integrare AI reală, minimală și sigură.
4. Evaluare comparativă pe câteva cazuri.
5. Stabilizare, deploy și pitch.
6. Freeze înainte de jurizare: fără feature-uri noi.

## Fără server de acasă la început
Lovable/Codex și GitHub pot fi folosite fără să ții un laptop suplimentar pornit. Un al doilea laptop are sens doar pentru teste locale sau o sarcină concretă; accesul remote adaugă configurare și risc.
